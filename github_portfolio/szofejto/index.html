The Core Idea

A Hungarian word puzzle game built as a practical, hands-on experiment in AI-assisted web development, structured prompt engineering, and continuous iteration.

Goals & Design Principles

The objective was to design a clean, responsive puzzle interface tailored for Hungarian character sets and logic, testing how effectively an AI-driven workflow can translate functional requirements into a working browser experience.

Execution & Value

Focused on clean state management, minimalist user feedback, and rapid prototyping principles—turning a simple conceptual prompt into a fully playable, deployed web application.
