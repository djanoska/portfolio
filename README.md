# Portfolio · Janoska David

Personal professional portfolio and digital product prototyping laboratory showcasing selected web applications, experiments, and interactive MVPs.

## 🌐 Live Site
👉 [davidjanoska.com](https://davidjanoska.com)

## 🛠️ Tech Stack & Architecture
* **Frontend:** HTML5, modern CSS3 (CSS Variables, Flexbox/Grid), SVG-based dynamic UI previews.
* **Hosting:** GitHub Pages via custom domain (`davidjanoska.com`).
* **SEO & Metadata:** Structured data (Schema.org Person Entity JSON-LD), Semantic markup, Open Graph metadata.
* **Analytics:** Cloudflare Web Analytics.

## 📂 Project Structure
* `/` – Main portfolio landing page (`index.html`)
* `/metronome/` – TempoCoach: Browser-based rhythmic utility and practice metronome.
* `/szofejto/` – Szófejtő: Interactive Hungarian word puzzle application.
* `/experiments/` – Prototyping lab and sandbox for AI-assisted frontend MVPs.
