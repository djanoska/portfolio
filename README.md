## 🛠️ Tech Stack & Architecture
* **Frontend:** HTML5, modern CSS3 (CSS Variables, Flexbox/Grid), SVG-based dynamic UI previews.
* **Hosting:** GitHub Pages via custom domain (`davidjanoska.com`), SSL security, and WAF protection.
* **SEO & Metadata:** Structured data (Schema.org Person Entity JSON-LD), Semantic markup, Open Graph metadata.
* **Analytics:** Cloudflare Web Analytics.
